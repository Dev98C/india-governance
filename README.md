# India Governance — State Performance Observatory

## v0.26
Interactive research dashboard comparing Indian states across growth, real incomes, poverty reduction, human development, fiscal health, labour markets, infrastructure and investment.

This repository contains the current static prototype. The analytical model uses a 20-year political window (2006–2026), separates BJP-dominant, non-BJP-dominant and mixed states, and keeps nominal GSDP CAGR as a diagnostic rather than a scored component.

### Composite weights
- Real GSDP CAGR — 20%
- Real per-capita NSDP CAGR — 15%
- Poverty reduction — 15%
- Human development — 20%
- Fiscal health — 15%
- Employment & economic structure — 10%
- Infrastructure & investment — 5%
- Nominal GSDP CAGR — diagnostic only

### Main views
- Overview: 20-year report card and BJP vs non-BJP group comparison
- States: ranked state explorer with category-specific sorting
- State profiles: Core Indicators, Labour Market, Human Development, Infrastructure and Investment
- Last 5 Years: separate state sub-page comparing recent performance with the state's own long-run benchmark
- Compare: side-by-side state comparison with India benchmark markers
- Methodology: assumptions, weights and source notes

### Important research note
This remains a research prototype. Some category-level inputs are inherited from the working analysis and should be revalidated against final source tables before publication as a formal index.

### Sources used in the research
RBI / MoSPI Handbook of Statistics on Indian States; MoSPI Periodic Labour Force Survey; NITI Aayog SDG India Index; NITI Aayog Fiscal Health Index; NITI Aayog Multidimensional Poverty Index; DPIIT LEADS; NITI Aayog Export Preparedness Index and India Electric Mobility Index; NCAER State Investment Potential Index.
